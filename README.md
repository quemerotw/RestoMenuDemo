# 🍽️ RestoMenu - Menú Digital Inteligente

¡Bienvenido a **RestoMenu**! Una solución moderna y eficiente para locales gastronómicos que buscan digitalizar su carta y optimizar la atención al cliente. 

Este proyecto está desarrollado con **HTML5, CSS3 y JavaScript puro (Vanilla JS)**, garantizando una carga ultra rápida y una experiencia de usuario fluida sin dependencias pesadas.

---

## 🚀 Características Principales

* **📱 Diseño Responsive:** Optimizado al 100% para dispositivos móviles (escaneo de códigos QR).
* **🛒 Carrito de Compras Dinámico:** Los clientes pueden sumar productos y ver el subtotal en tiempo real.
* **🟢 Integración con WhatsApp:** El pedido se envía directamente al número del local con un detalle formateado.
* **⚡ Sin Base de Datos:** Los productos se cargan desde un archivo de configuración simple, facilitando el despliegue rápido.
* **📊 Estadísticas:** Integrado con Google Analytics para medir visitas y conversiones.
